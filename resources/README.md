# Resources

Keep references and approved learning/project resources here.

Suggested contents:
- `references.md`: papers, documentation, articles, and access dates.
- Dataset cards describing source, license, fields, limitations, and preprocessing.
- Approved small sample data or links to the authoritative download source.

Do not commit copyrighted material, confidential data, API keys, or large generated datasets without approval. Document provenance and license for every external dataset.
