# Capstone Materials

This folder is the organized entry point for capstone-specific material within the personal repository. The application and its existing documentation remain in their current locations.

Maintain:
- A concise project brief and scope
- Links to architecture and engineering documentation
- Experiment/result summaries with reproducibility notes
- Demo and presentation links
- A record of individual contributions that reflects actual work

The guidelines also ask for a team capstone repository. This folder does not substitute for a separate team repository if the instructor requires one.
