# Assignments

Store assignment briefs, solutions, supporting datasets (when permitted), and short result notes here.

## Recommended convention
- Use one folder per assignment: `A01-topic/`, `A02-topic/`, etc.
- Include the original task/requirements, solution, and a short validation note.
- Do not commit secrets, private student data, or files you do not have permission to redistribute.
- Link notebooks or reusable implementation from the relevant assignment instead of duplicating large files.
